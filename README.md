# The Turbulence Identity Problem

## A Falsifiable Experimental Criterion

This repository contains a proposed empirical adjudication framework for one deliberately bounded version of the turbulence identity problem.

The scientific question is not whether turbulence can be recognized descriptively or whether every turbulent flow can be modeled by one convenient representation. It is whether, within a declared canonical scope, one operational criterion can be necessary across independently accepted turbulent regimes and sufficient against difficult neighboring cases.

The candidate tested here is:

**turbulence ⇔ DLBTF ∧ HFN**

where:

**DLBTF** = Distributed Load-Bearing Transfer Flow

**HFN** = History-Family Nondegeneracy

The equivalence is a candidate empirical hypothesis, not a reported result.

The first-closure scope, Σ_C, is restricted to established three-dimensional, single-phase, constant-property, non-rotating, non-stratified, non-buoyant, incompressible Newtonian Navier–Stokes turbulence in canonical homogeneous, free-shear and smooth-wall flow families, away from laminar–turbulent transition.

The protocol is designed to return one of three global scientific dispositions:

**CLOSED WITHIN Σ_C**

**NOT CLOSED WITHIN Σ_C**

**NOT YET ADJUDICABLE WITHIN Σ_C**

A competent positive counterexample can defeat necessity. A competent nonturbulent comparator satisfying the complete criterion can defeat sufficiency. Unresolved evidence remains unresolved rather than being converted into support or falsification.

The transfer-side experiment tests whether causally required nonlinear-transfer support remains uniformly bounded or exhibits supported opening across a preregistered finite physical enlargement ladder. Causal Transfer Response Rank supplies a finite, tolerance-aware lower-bound route; it does not claim infinite complexity or a globally minimal turbulence-model dimension.

The history-side experiment separately tests whether an independently warranted regime supports a nondegenerate family of realized histories or is exhausted, at the frozen level and horizon, by a dynamically thin recurrent family.
